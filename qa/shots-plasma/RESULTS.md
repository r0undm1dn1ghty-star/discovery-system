# Плазма: фон читался чёрным → приведён к бренду #111524 (замер пикселями)

Правка: `ds-plasma.js` (единственный изменённый файл). `ds-base.css` не тронут
(правило `canvas[aria-hidden="true"]` и токены `--bg`/`--accent` — как были).

## Причина (числами)

1. Палитра кадра была привязана к **почти чёрной** базе `#0d0d14 = (13,13,20)`,
   а не к фону страницы `#111524 = (17,21,36)`.
2. Поле шума физически не доходило до середины палитры: на кадре 1440×1200
   `n̄ = 0.22`, `n ∈ [0.09, 0.33]` → в `shade()` множитель `n*1.6 ≈ 0.35`,
   то есть 65 % кадра стояли у самой тёмной точки палитры, а «highlight» `#4a6191`
   (порог `n>0.62`) не включался вообще — мёртвая ветка.
3. Виньетка **умножала** края на `dim = 1 - min(0.55, edge)` → до 0.45 яркости,
   при этом аддитивно подмешивала `edge*0.35` в `n`. Итог: центр (27,34,51),
   края/углы (13,14,23). Замер «до» подтвердил: min (12,14,22) … max (30,40,58)
   при цели (17,21,36).

Доминирующий цвет страницы «до»: `(12,12,24)` — нейтрально-чёрный (20–23 % пикселей).

## Что изменено в ds-plasma.js

| Строки | Что |
|---|---|
| 1–9 | шапка: описан новый принцип (кадр центрируется на бренд-тоне) |
| 29–42 | `BRAND` — точка привязки: читается из `getComputedStyle(body/html).backgroundColor` (фолбэк-константа `#111524`, отбраковка прозрачного/чёрного); `AMP=9`, `TONE=[0.72,0.92,1.3]`, `MID_CURVE=0.8`, `EDGE_MAX=0.55`, `EDGE_K=0.5` |
| 112 | удалены `A/B/C` и `shade()`/`mix()` (палитра больше не нужна) |
| 114–163 | `drawFrame()` переписан: проход 1 — поле `fbm` + среднее/размах кадра; нормировка `s=(n-n̄)/maxdev ∈ [-1..1]`, кривая `s^0.8`, повторное центрирование (`s̄→0`) ⇒ **средний тон кадра равен BRAND по построению**; проход 2 — `цвет = BRAND + AMP·s·TONE·k`, `k = 1 - min(EDGE_MAX, edge·EDGE_K)` — виньетка сжимает **контраст** плазмы к бренду, а не затемняет края |
| 115 | `if (!W \|\| !H) return;` — фикс pre-existing бага (см. ниже) |
| 209–213 | в `window.__dsPlasma` добавлен геттер `brand` (для QA-замера) |

Отклонение от BRAND ограничено `AMP·TONE = (6.5, 8.3, 11.7) ≤ 12` арифметически,
т.е. фон не может выйти за бренд-допуск ни при каком кадре/вьюпорте.

### Побочно найденный баг (тоже исправлен, 1 строка)

`resize()` выставляет `W/H` внутри `requestAnimationFrame`, а `drawStatic()` при
`prefers-reduced-motion` вызывался синхронно → первый `drawFrame()` шёл при `W=H=0`
и падал: `InvalidStateError: drawImage ... canvas with a width or height of 0`
(проверено `window.onerror`). Скрипт умирал до экспорта `window.__dsPlasma`
(QA-хук отсутствовал, `mode=-`). Статичный кадр всё же дорисовывался позже из rAF,
поэтому визуально баг был незаметен. Гвард `if (!W || !H) return;` его убрал.

## Как воспроизвести

```bash
cd discovery-system-repo
python -m http.server 8791 --bind 127.0.0.1            # из корня репо
# статичный кадр (детерминированный, t=7.3) — «до» нужен старый файл:
cp ds-plasma.js /tmp/new.js
python -c "s=open('channel.html').read();open('_old.html','w').write(s.replace('ds-plasma.js','qa/shots-plasma/ds-plasma-before.js'))"
DS_RM=1 node qa/shots-plasma/shoot.js out/before.png 1440 1200 http://127.0.0.1:8791/_old.html
DS_RM=1 node qa/shots-plasma/shoot.js out/after.png  1440 1200 http://127.0.0.1:8791/channel.html
python qa/shots-plasma/compare.py out/before.json out/after.json --label "channel 1440"
rm _old.html
```

Инструменты: `shoot.js` (CDP-скриншот вьюпорта 1:1 + карта пустых точек фона),
`measure.py`/`stats.py`/`compare.py` (Pillow), `filter.py` (отсев не-фоновых точек),
`sim.js` (офлайн-модель кадра для подбора параметров — совпала с реальным
рендером: legacy t=7.3 дал mean (16,19,32) против замеренных (16,19,32)),
`liveness.py` (динамика/плоскость), `candidates.json` (перебор конфигов),
`ds-plasma-before.js` — копия старого файла из git HEAD для «до».

Скриншоты: `static-{before,after}-{channel,index}-{1440,390}.png`,
`after-*.png`, `live-channel-1440.png`, `killswitch-1440.png`,
`anim-old-*.png` / `anim-new-*.png` (для проверки живости).
