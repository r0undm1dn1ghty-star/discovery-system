# Диаграммная палитра Discovery System

**Статус гейта diagram-design:** пройден кастомной палитрой Discovery (ветка «пользователь дал токены»),
установленный скилл `diagram-design` не менялся. Профиль `~/.diagram-design/profiles/*.md` не создавался —
см. «Почему так» ниже.

Этот файл — единственный источник правды для диаграмм этого репозитория. Если появится вторая диаграмма,
она берёт роли отсюда, а не из шипнутых дефолтов скилла (paper `#f5f5f5` / ink `#2d3142` / accent `#bf4520`).

## Роли

| Роль | Значение | Где применяется |
|---|---|---|
| `paper` | `#111524` | фон страницы и диаграммы |
| `paper-2` | `rgba(255,255,255,.03)` | заливка контейнеров/карточек |
| `ink` | `#eef2f9` | имена стадий, узловые подписи, главный текст |
| `body` | `#b8c3d6` | описательный текст |
| `muted` | `#8893a8` | подписи, уровни, служебные метки, базовая линия кривой |
| `faint` | `#5a6275` | самый тихий текст (сноски) |
| `rule` | `rgba(255,255,255,.12)` | хайрлайны, границы, оси |
| `rule-soft` | `rgba(255,255,255,.07)` | мягкие разделители внутри блоков |
| `accent` | `#7bc4a8` | 1–2 фокальных элемента на диаграмму (провал пути + метки трения) |
| `warn` | `#e0a458` | только для «до / было» — в схемах пути не используется |
| `ok` | `#5ed9a8` | кнопки действия (в схемах не используется) |
| `btn` | `#1f7a4d` / `#f2fbf5` | заливка CTA, если в диаграмме есть кнопка |

## Типографика

| Роль | Семейство | Размер / начертание |
|---|---|---|
| Заголовок страницы (h1) | **Onest** | `clamp(1.9rem, 4.6vw, 2.9rem)`, 700 |
| Имя стадии / узла | **Onest** | 14–15px, 600 |
| Название блока (h2) | **Onest** | `clamp(1.25rem, 2.4vw, 1.6rem)`, 700 |
| Описательный текст | **IBM Plex Sans** | 11–12px (в SVG), 1.45 |
| Надзаголовки, уровни, метки строк, пути файлов | **IBM Plex Mono** | 8–10px, uppercase, `letter-spacing:.08–.12em` |

Шрифты — из репозитория, файл `fonts/fonts.css` (Onest + IBM Plex Sans/Mono), без внешних CDN:
страница должна открываться локально и на discovery-system.ru одинаково.

Отличия от шипнутых дефолтов скилла (осознанные): Instrument Serif не используется (в бренде его нет),
Geist заменён на Onest/Plex, монospace — IBM Plex Mono (нигде не JetBrains Mono), палитра тёмная,
а не светлая бумага.

## Почему так

- Палитра и типографика диаграммы совпадают с `:root` страниц сайта (`proof.html`, `ds-base.css`),
  иначе артефакт читается как чужой на фоне discovery-system.ru.
- Пользователь задал токены явно в задаче — это ветка (d) «paste tokens» из `references/onboarding.md`,
  поэтому вопрос первого запуска не задавался, а шипнутый `style-guide.md` не трогался.
- Именованный профиль в `~/.diagram-design/profiles/discovery.md` + маркер `.diagram-design` в корне репо
  не заводились: задача ограничила изменение скилла файлом палитры в репо. Если диаграмм станет больше,
  палитру стоит сохранить профилем (`save discovery`) и поставить маркер — тогда гейт перестанет спрашивать
  в этом проекте навсегда.
